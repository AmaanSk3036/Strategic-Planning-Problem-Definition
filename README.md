# Strategic-Planning-Problem-Definition
This report presents an exploratory data analysis (EDA) of the Online Retail dataset, which contains the transactions of a UK-based online retailer between 1 December 2010 and 9 December 2011. The work was carried out in Python (pandas, NumPy, Matplotlib and Seaborn) inside a Jupyter Notebook. It contains loading , cleaning data to visualisations.
